# 阶段 2 云同步：跨平台端到端证据（Android ↔ Linux）

> 采集 2026-09-20。**只记录实跑结果。**
> 环境：宿主 CachyOS Linux（x86_64，有 /dev/kvm）；Android 模拟器 = AVD `lr-e2e`（`system-images;android-35;google_apis;x86_64`）；服务端 = 本机 `sync-server/server.py`（Python 标准库，端口 8799，账号 `e2e`）。

## 1. 复现命令

    bash sync-server/e2e-cross-platform.sh

脚本流程：起服务端 → **Linux 客户端写入（seed）** → **Android 客户端拉取 + 并发修改 + 推送** → **Linux 客户端校验（verify）**。

## 4. 验证了什么

| 断言 | 谁断言 | 内容 |
| --- | --- | --- |
| Android 能拉到 Linux 的数据 | Android | 阅读进度 `chapterIndex == 3`、生词 `lantern` 释义 `n. 灯笼` |
| 同书进度冲突由更晚的一方胜出 | Linux | Android 把进度改到 `chapterIndex == 9` 后，Linux 侧拉到 9 |
| 同一条生词并发编辑可合并 | Linux | Android 改释义 + 复习到 level 3 后，Linux 侧看到 `n. 灯笼；提灯` 且 `reviewLevel >= 3` |
| **同一条术语备注并发编辑取更晚** | Android + Linux | Android 先拉到 Linux 的 `Linux 备注`；Android 写入 `Android 备注（更晚）` 后，Linux verify 侧校验到该值 |
| 冲突收敛、队列清空 | Android | `unresolved.isEmpty()`、`pending == 0` |

脚本整体退出码：`SCRIPT_EXIT=0`（三段 Gradle 调用全部 BUILD SUCCESSFUL，Android 仪器测试 1/1 PASS）。

跨平台路径全部走真实网络：Android 经 `http://10.0.2.2:8799` 访问宿主服务端，Linux 客户端走 `http://127.0.0.1:8799`；两边都用各自的平台凭据存储（Android Keystore / 内存假实现用于宿主步骤）。

## 6. 未验证 / 边界（不夸大）

- 术语备注冲突已纳入跨平台脚本（见 §4 第四行），但它走的是**协议层**（测试直接调 `HttpSyncApi.push/pull`），没有串到 Android 应用的术语表存储（`:app` 的 BookGlossaryRepository 尚未接入 LocalSyncSource）。
- 「离线」在跨平台脚本里是**逻辑离线**（一端先不同步），没有真的切断模拟器网络。
- **Windows / macOS 客户端尚未参与**：本机只有 Linux；三平台产物靠 GitHub Actions `Platform Build`。
- 服务端使用 **HTTP**（内网回环）跑通；**自签证书 + 指纹固定**的 HTTPS 路径由 HttpSyncApi 单测覆盖，未在模拟器上做真证书联调。
