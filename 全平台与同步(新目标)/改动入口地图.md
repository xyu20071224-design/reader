# 改动入口地图（三平台 + 云同步）

> 用途：以后要改这个项目时，先在这里定位「该动哪些文件」。

## 0. 三条铁律（任何时候都适用）

1. **Gradle 根在 src/**，命令走 toolchain/build.sh（Linux）/ toolchain/build.ps1（Windows），不要裸调 gradlew。
2. **:shared 禁 android.*/androidx.***（CI 有 grep 执法）；新增同步逻辑放 :shared，平台差异放各自壳。
3. **不动 readest-src/、Readest/**（第三方参考，已 gitignore）；不引入第四种平台。

### 1.3 客户端内核（src/shared/src/main/java/com/linguareader/shared/sync/）

| 文件 | 职责 | 什么时候改 |
| --- | --- | --- |
| SyncModels.kt | 记录信封/分页/结果/SyncException | 协议字段变化 |
| SyncCollections.kt | 四个集合常量（progress/vocabulary/glossary/preference） | 新增同步类别 |
| SyncPayloadCodec.kt | 模型 <-> 记录编解码（设备本地字段不进 payload） | 模型字段或同步范围变化 |
| SyncApi.kt | 传输接口（含 setToken 默认实现） | 新增传输能力 |
| HttpSyncApi.kt | HTTP 实现 + 自签证书 SHA-256 指纹固定 + 书籍正文分片/续传/Range 下载 | 网络层、证书、blob |
| SyncBlobApi.kt | 书籍正文接口与数据类型 | 正文同步语义 |
| SyncEngine.kt | 推送 -> 冲突合并重推 -> 游标拉取；离线保留 outbox | 同步流程 |
| ConflictResolver.kt | 冲突裁决语义（进度 LWW/生词字段合并/文本 LWW） | 冲突策略（先改文档） |
| SyncMerger.kt | 按集合分派合并 + 墓碑优先 | 同上 |
| SyncStateStore.kt | 游标 + outbox + 已同步水位（文件/内存实现） | 本地状态结构 |
| SyncCoordinator.kt | 登录/登出/会话恢复 + 快照增量入队 + 驱动引擎 | 编排与水位策略 |
| SyncSettings.kt | 服务器地址/用户名/证书指纹（令牌不在此） | 设置项增减 |
| SecretStore.kt | 凭据存储接口 + 文件兜底实现 | 凭据接缝 |
| SyncSource.kt | 平台侧接缝（snapshot/apply） | 接缝签名 |
| LocalSyncSource.kt | 用真实书库/生词本仓库实现的接缝 | 同步数据范围扩大 |
