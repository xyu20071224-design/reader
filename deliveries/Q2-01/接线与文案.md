# 版本历史接线与双语文案

## 调用接口

```kotlin
val identity = BuildReleaseIdentity(
    BuildConfig.VERSION_NAME, BuildConfig.VERSION_CODE,
    BuildConfig.SOURCE_COMMIT.takeIf { it.isNotBlank() }, BuildConfig.SOURCE_DIRTY
)
val history = AppReleaseHistoryRepository(context, updateRepository, identity)
val initial = history.loadLocal(updateRepository.nativeStatus().loadedRevision)
```

**应用每次启动都应调用 loadLocal，而非等用户首次打开历史页面再调用。** 这只访问本地，
用于观测实际安装版本，才能在下一次版本变更时保留上次版本；打开页面/启动都不刷新网络。
该观测与“已读”分开，不会自动把新说明标为已读。之前没有记录时返回 FIRST_OBSERVED，
不把“首次观测”说成已证明的首次安装，也不从旧启动广告的 last_seen 推测实际安装版本。

- `loadLocal(nativePatchRevision = 0)`：本地视图，零网络。
- `refresh(nativePatchRevision = 0)`：只有用户点击刷新时调用；遍历统一 currentSource 分页，失败保留不完整标记。
- `markRead(nativePatchRevision = 0)`：用户显式已读；读标识含实际构建及加载补丁修订。
- `invalidate()`：换源或取消当前视图请求；仓库同时读取 updateRepository.sourceGeneration 防同 URL 重选旧响应。
  源切换先调用 invalidate 再设置源，保留原来的请求取消/视图代际检查；invalidate、新 refresh 与最终
  缓存发布共用锁，临时文件写完后在锁中重查来源、代际、请求与取消状态，再发布。

nativePatchRevision 传当前**实际已加载**的修订号，不传最高见过/已撤销的号。
AppReleaseHistoryView 独立于 AppUpdateUiState：不要因无更新、取消下载或补丁状态改变而删除历史。
集成人为书架/公共设置接常驻入口，展示 ReleaseHistorySheet 或独立 ReleaseHistoryContent；
两者通过 ReleaseHistoryLabels 接收文案，本提交不编辑公共 strings.xml。

## 构建与随版资料

SOURCE_COMMIT 和 SOURCE_DIRTY 由实际构建装配提供；Git 失败时保守为 dirty。当前版本说明
只有 versionName、versionCode、真实 tag commit 与 clean 状态全部匹配才出现。未知或未发布
构建显示空态；已有正式发布档案仍可在“发布历史”查看，不能冒充当前构建的改动。

已保存真实公开 v2.3.1 档案，commit 为 ad20253，前版 v2.3.0 为 69c6123；当前开发分支的新
修复不属于它。增加 assets 需要新 APK；后续发布资料用 build_release_notes.py 在最终源码
及真实 tag 边界生成，不能把当前 HEAD 的未发布修复写回旧版说明。

## 双语资源建议

函数字段用对应资源的格式化回调构造，不在组件中硬编码。

| Labels 字段 | 资源 key | 中文 | English |
| --- | --- | --- | --- |
| title | release_history_title | 版本改动 | Version changes |
| currentTab | release_history_current_tab | 本版 | This version |
| upgradeTab | release_history_upgrade_tab | 本次升级 | This upgrade |
| historyTab | release_history_all_tab | 发布历史 | Releases |
| refresh | release_history_refresh | 刷新历史 | Refresh history |
| refreshing | release_history_refreshing | 正在刷新 | Refreshing |
| markRead | release_history_mark_read | 标为已读 | Mark as read |
| read | release_history_read | 已读 | Read |
| missingCurrent | release_history_current_missing | 此构建尚无已核实的本版说明，可查看发布历史。 | Verified notes for this build are unavailable. You can view published releases. |
| previousUnknown | release_history_previous_unknown | 没有上次安装版本的记录，无法确定本次升级范围。 | The previous installed version was not recorded, so this upgrade range is unknown. |
| noUpgrade | release_history_no_upgrade | 此次未记录跨版本升级。 | No version upgrade was recorded. |
| emptyHistory | release_history_empty | 尚无可显示的发布说明。 | No release notes are available yet. |
| emptyNotes | release_history_notes_empty | 此版本尚未提供说明正文。 | Notes were not provided for this release. |
| notLoaded | release_history_not_loaded | 在线历史尚未加载，本地说明仍可查看。 | Online history has not been loaded. Local notes remain available. |
| incomplete | release_history_incomplete | 版本历史未完整加载，当前列表可能缺少版本。 | History is incomplete and may be missing releases. |
| cached | release_history_cached | 正在显示已保存的发布记录。 | Showing saved release records. |
| failed | release_history_failed | 暂时无法完整读取发布记录，请重试。 | Some release records could not be read. Please try again. |
| currentVersion | release_history_current_version | 当前版本 %1$s | Current version %1$s |
| releaseRange | release_history_release_range | 本版改动：%1$s → %2$s | Release changes: %1$s → %2$s |
| upgradeRange | release_history_upgrade_range | 本次升级：%1$s → %2$s | This upgrade: %1$s → %2$s |
| downgrade | release_history_downgrade | 从 %1$s 降级到 %2$s。 | Downgraded from %1$s to %2$s. |
| patchRevision | release_history_patch_revision | 已加载热修复修订 %1$d | Loaded hotfix revision %1$d |

启动说明仅在 currentNotes != null && unread 时考虑展示，未发布构建不拿历史档案冒充当前说明。
刷新必须调用 refresh，打开/关闭、选 tab、标为已读不应产生网络请求。加载状态由调用方持有，
将 loading=true 传入组件避免重复点击；源变更先取消原请求并重建/刷新本地视图。
