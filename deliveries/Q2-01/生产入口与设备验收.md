# 版本历史生产入口

书架新增常驻“版本改动”文本入口，独立于更新检查及下载状态。应用每次启动仅加载本地历史并观测实际构建；只有用户明确刷新才请求网络。切换来源先使历史请求失效、取消任务，再切换来源并加载其本地档案。

启动说明只在真实构建身份匹配且未读时展示同一份已核实正文。普通关闭不写已读；“知道了”和历史页“标为已读”才写标记。未发布构建使用问候和诚实空态，既有正式说明保留在发布历史。旧启动说明的字符串插值也已修正，避免显示模板文字。

集成回归 `history-ui-app`：原始 XML 合计19项、0失败、0错误、0跳过；含历史仓库6、收藏反馈7、真实收藏持久化5及相邻句仓库1。相关应用与测试 APK 构建通过。

设备 `ReleaseHistoryInstrumentedTest` 在任务专用 API35 模拟器断网（Wi-Fi/移动数据均关闭，结束后恢复）通过：直接从书架进入、显示当前未核实构建空态、查看内置 v2.3.1 历史、Activity 重建保留页面/安装观测、普通查看不改已读，显式操作后显示已读。证据 `artifacts/device-history-phrase/instrumentation.txt` 和 `offline-settings.json`。同批另一个词组设备测试当时因未区分全局/面板提示选择器而失败，不能将整批宣称全绿；历史用例单项明确通过。

真实新版发布、签名安装及正式版本跨安装仍待实际发布条件；本次不发布、签名或伪造新版本说明。
