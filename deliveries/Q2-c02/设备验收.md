# 设备测试交接

新增 `com.linguareader.app.packs.PackLifecycleInstrumentedTest`，4例。只允许 `.verify` 隔离
应用，目标设备继续由根代理独占。子代理仅编译测试源码，没有运行/获取设备或签名APK。

主机已生成 `artifacts/q2-c02/device-fixtures/`，bookId为 `fe5e477772af22788660`，固定
engineTag为 `server:http://127.0.0.1:18765@d1c63ad4`，voice为 `narrator.wav`，pipeline3。
包内为实际1秒MP3正弦，ffprobe原始结果在 `fixture-audio-probe.json`。

重建工件：

```sh
ffmpeg -f lavfi -i sine=frequency=440:duration=1 -ar 16000 -ac 1 -codec:a libmp3lame /tmp/tone.mp3
python3 scripts/build_pack_lifecycle_fixtures.py --out artifacts/q2-c02/device-fixtures \
  --audio-mp3 /tmp/tone.mp3 --engine-tag 'server:http://127.0.0.1:18765@d1c63ad4' --voice narrator.wav
```

根代理先按现有签名/verify构建约定装好主APK与androidTest APK，再推工件并直接运行
instrumentation。不要在推完文件后再执行会重新安装/收尾卸载应用的全量 connected 任务。

```sh
adb shell mkdir -p /sdcard/Android/data/com.linguareader.app.verify/files/pack-fixtures
adb push artifacts/q2-c02/device-fixtures/. /sdcard/Android/data/com.linguareader.app.verify/files/pack-fixtures/
adb shell am instrument -w -e class com.linguareader.app.packs.PackLifecycleInstrumentedTest \
  com.linguareader.app.verify.test/androidx.test.runner.AndroidJUnitRunner
adb logcat -d -s PackLifecycleAcceptance:I
```

实际test包名/runner以根构建产物manifest为准。测试只清理白名单fixture包、其书缓存及临时
导入书目录，正常收尾恢复此前活动词典和TTS设置，不清其他用户音色或角色设置。

覆盖：

- 真实SQLite词典安装→查packprobe→升级→同版重装→拒降级→重开仓库→停用/丢文件/卸载，
  通过实际DictionaryRepository查词确认初版/新版和内置hello兜底。
- 真实文件系统registry临时路径阻塞：同版/新版替换和卸载失败保留原清单/样本，临时区干净。
- bundle部分成功保留dict/audio，完整成员装入；真实metadata与RIFF样本消费，升级/卸载后
  消费查询消失；卸载外bundle不级联删独立成员。正弦不冒充真人clone服务试听。
- 音频先清该fixture书缓存，实际TextImporter导入、PackRepository安装、真实Cloud.speak，
  必须收到MediaPlayer start+completion且errors=0、synthesize请求计数=0、没有MP3缓存副本。
  注入backend在此阶段禁止合成，不创建HTTP客户端；零请求证明不依赖loopback连接失败。
  卸载后单句prepareChapter必须进入显式测试backend一次，复制合法MP3至真实缓存并完成。
  因此没有调用任何真实计费/克隆服务，也不启动/依赖loopback服务。

本测试是消费者/实际设备codec验收，不替代用户界面列表/提示/试听选择操作。设备原始结果由根
追加，未运行前只能记“已编译、待设备执行”。额外发现的缺文件verify抛FileNotFound已有修前
JVM红证据；修正为Rejected后回归，避免设备丢文件校验与UI校验异常退出。
