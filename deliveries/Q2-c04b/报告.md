## 已实现的行为

- 默认 `ORIGINAL` 继续原始父片段播放。`PHRASES` 通过可选 `PlannedTtsSynthesizer` 能力消费同一个 `ProsodyPlanner`，只在足够长的自然边界分句，保护引号、跨块引语、括号、数字、缩写和 URL。保留原书/章/句/声部/角色与原文坐标，不持久化 `partIndex`。
- 系统 TTS 逐部分提交文本并应用本地 rate；云端 MediaPlayer 逐部分播放、变速。`PlannedSpeechRunner` 对父请求只报一次 start/done/error，并细化当前原文高亮。内部停顿、旧子事件、暂停/跳句/新请求由代次隔离；最后一部分不额外叠加内部停顿。
- 云端章节/整书预生成与播放使用同一规划器、引语上下文、音色解析与短语缓存身份。PHRASES 只生成子音频，不同时生成完整父音频。相同文件的预生成/播放等待同一在途合成，避免重复计费。
- `TtsPipelineContract.VERSION=3`、原始 `TtsCacheKey` 格式、音频包 manifest 和句/声部映射保持；默认 MiMo engineKey 完全兼容，仅非默认实际模型增加 `@model-<SHA8>` 后缀，隔离旧实现误用默认模型生成的完整音频。短语缓存位于 `<book>/<chapter>/prosody-v1-<SHA>/s<sentence>-<segment>-p<part>.mp3`，与旧完整缓存分离；统计、LRU、章节保护、按书清理已实际测试。
- 短语身份绑定引擎、有效音色、父定位、源/部分文本、规划缓存版本、实际合成配置。真实配置包括后端模型、保留大小写的请求端点、样式、MiMo 设计描述、克隆样本内容 SHA 与格式。凭证不进入身份，路径仅含 SHA。仅本地调速、内部停顿/倍率变化且文本边界相同时复用音频。
- 旧音频包命中且未显式授权重新合成时，继续原始节奏，报告 `AUDIO_PACK_ORIGINAL`，不会因选择 PHRASES 绕包计费。无 planned 能力的后端继续原始节奏，报告 `UNSUPPORTED_BACKEND`。
- 模式可持久化；重新合成权限只在会话内，默认 false，换书/停止撤销。无听书会话时保存模式不会启动服务；有会话时由服务传给引擎。播放中切换会取消旧请求并重新准备；整书缓存旧进度/完成回调不会串入新模式或卡住“缓存中”。
- 核对实际请求发现 MiMo 实例 `modelFor` 原先未传给真实请求，已补接并验证请求体：预置音色使用配置模型，设计/克隆使用各自固定模型。

## 对外接口

```kotlin
TtsPlaybackController.prosodyMode(context): ProsodyPlanner.Mode
TtsPlaybackController.setProsodyMode(
    context, mode, allowAudioPackRegeneration = false
)
TtsPlaybackController.onCloudSettingsChanged(context, prosodyMode = selectedMode)
```

`ProsodySettings` 仅保存 ORIGINAL/PHRASES；设置页普通模式选择必须保持默认 false。状态新增：`prosodyMode`（请求值）、`prosodyEffectiveMode`（实际值）、`prosodyFallbackReason`。旧包回退/后端不支持需由 UI 可见提示。设置页同时保存引擎与模式时，必须先 `CloudTtsSettings.save`，再只调用一次带模式的 `onCloudSettingsChanged`；不要额外调用即时模式 setter。合并动作在旧后端关闭后配置新后端，避免双准备/双请求。默认 UI 不提供绕过旧包按钮的集成决定不变。

## 验证与未验证边界

构建使用 macOS、JDK 17、Gradle 8.11.1、SDK 35；Android 适配器与 Service 已实际编译。最终直接相关测试与原始 XML 统计以同目录 `验证结果.json` 为准。测试包括共享播放/规划/原文坐标/多角色/取消/缓存键/打包契约，以及真实系统适配器（ShadowTextToSpeech）、云适配器（fake 合成后端和 ShadowMediaPlayer）、旧包零合成请求、显式授权、预生成不生成父音频、配置变化/调速复用、LRU/统计/清理、Controller→Service 待播传递。

Robolectric 没有生成可试听音频，fake 云测试的零请求指零 synthesize 调用，不是实云网络抓包。系统真机首音、候选 100/160ms 内部停顿和 0.96 尾段倍率的自然度、真实云音频与速度听感均待设备/凭证验收；不得标成全量完成。设备/完整应用 UI 流程由集成人串行验证。

自建服务未提供同一 voice ID 内容修订号，无法发现远端静默替换音色；更换 ID/配置或清缓存恢复，不新增轮询。默认原节奏缓存/包身份按既有契约保留；非默认 MiMo 模型有最小身份后缀，不再命中旧默认模型音频，旧文件保留。Original 设计/克隆历史身份不全面迁移，同 ID 音色内容改变仍需换 ID 或清旧完整缓存。短语新命名空间已绑定已知音色内容 SHA。

## 风险与回退

分句可能增加云合成请求数，也可能打断模型自身韵律；因此默认原始节奏，分句参数仍是待试听候选。选择 ORIGINAL 可立即回到原始播放和既有包/缓存，不删除音频。若退代码，短语目录可留待现有配额/清理处理；没有 schema 或 pipeline 数据迁移。设备未验收和实云未试听时，状态应写“运行时及自动回归已实现，设备/实云听感待验”。
