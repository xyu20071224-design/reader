## 兼容边界与原包之外的补齐

独立资源仓库 `app/packs/RemotePacksRepository.kt` 是本次重新接线的关键：发现使用 CAS 代际，失败/取消不复活旧选择，下载只用私有目录快照。服务器端返回的是可复用内容缓存，失效只丢结果；GitHub 传输返回独占临时文件，才按其所有权清理。调用者可变镜像列表不作为下载时的权威元数据。这两处所有权/快照缺陷已有修前红记录，修复包含在 `2a15300`。

APK 更新、native patch 和 release history 继续使用原来的 `AppUpdateRepository` / `ReleaseSource` 链。保留精确来源代际、大小/摘要、补丁 catalog 完整性与原 trustedAsset/签名/精确 base/revision 检查；资源服务器不能扩张这条信任边界，也不自动成为 APK 或历史源。固定 GitHub 备用使用实际发现的 `ReleaseAsset` 与既有 transport/policy，未知大小资产不启用下载。

原包之外新增 `deploy/packs/package.mjs`、`activate.py`、`install_config.py` 及相应测试，承担整体归档校验、已有目录合并、原子激活、配置恢复与实际 HTTP 检查。桌面端另在 `662cff8` 接资源管理与词典消费，`0ee8128` 修正点词边界；这些不是对原 21 文件快照“原样采纳”的证明。后续真实服务器/设备分阶段测试为 `626ce1f`、`a7213d0`，测试源码提交与最终实跑通过分别记账。
