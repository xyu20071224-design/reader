# 下载来源入口与切换保护

2026-11-24，集成分支新增更新页常驻的下载来源选择。默认 GitHub；用户可明确保存 HTTPS 镜像目录文件地址。输入校验复用实际来源策略，不额外放宽协议。更新和在线资源包使用同一设置。

切换来源会取消检查、更新下载及资源包列表/下载任务，清空旧来源可见结果；结果与进度回调带选择代际保护。已安装资源与自动检查偏好保留。资源安装或补丁应用/待重启时禁止切换，防止打断提交阶段。

- `source-ui-compile`：Android 生产代码编译通过。
- `source-and-storage-app`：原始 XML 合计9项、0失败、0错误、0跳过（来源仓库8项及档案取消1项）。
- `source-device-apks`：档案持久化7项通过；任务专用并存 APK 与测试 APK 构建通过。
- API35 任务专用模拟器上的 `UpdateSourceInstrumentedTest`：1项通过。实际 MainActivity 路径验证 HTTP 地址被拒且不改设置、HTTPS 保存后显示、Activity 重建保留、切回 GitHub 且自动检查仍关闭。
