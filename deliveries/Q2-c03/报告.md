## 实现

- `ReleaseSource` 提供分页发布与正式最新版，`ReleaseRecord` 保留无 APK 的版本说明。
- `ReleaseAsset` 分离原 GitHub canonical 身份和实际传输 URL；镜像必须有精确字节数与 SHA-256。
- GitHub/静态适配器共用可注入传输；静态页、资产和重定向限于用户明确选择的 HTTPS 同源目录。
  未来协议、错误仓库、路径越界、重复标识、缺失最新版或循环分页明确失败，不伪装为空历史。
- HTTP 下载有上限、精确大小与哈希检查；缺省资产大小时仍检查 HTTP Content-Length。
  取消、短读、错哈希、越界跳转等失败删除本次临时文件；不会覆盖已有补丁合并输入。
- `AppUpdateRepository.check/fetchPackAssets/download/downloadPack` 已接实际源；设置可持久选择目录。
  源 epoch 阻止切源后的旧响应或旧下载结果复活。默认 GitHub 下保留既有直接下载调用兼容；
  镜像要求来自发现快照且 sourceId 匹配，不扩大镜像策略。
- 镜像的 `native-patches.json` 自身先受 128 KiB、目录声明大小/哈希验证，再交旧
  `NativePatchCatalog`；补丁的 canonical URL、原证书、精确基础 APK 和签名修订校验均保留。
  本项没有修改 `NativePatchCatalog.trustedAsset` 或 `NativeHotfixRuntime`。
- `scripts/build_release_mirror.py` 只处理已下载的本地原资产，使用不可变 generation，最后原子切换
  根目录文件。不会部署、联网、重建或重新签名 APK。

## 集成人接线

- 设置读取：`AppUpdateSettings.catalogUrl: String?`；null 表示 GitHub。
- 设置写入：`repo.setCatalogUrl(value)`；空白清回 GitHub，验证 HTTPS 目录，保留 autoCheck。
- `repo.currentSource()` 仅构造当前源，供独立历史仓储共用；构造不联网。
- 设置切源前取消现有下载，清理 `AppUpdateUiState.info` 与远端包列表/错误/下载状态；不要清已安装包。
  原生补丁合并/待重启期间的 UI 调度继续遵循原更新状态机。
- 保留默认自动检查关闭；只有用户手动动作或已显式启用的既有自动检查触发请求。
- APK 最终包名/签名/覆盖升级仍由安装路径验证；本地字节 fixture 下载测试不代表真实 APK/设备升级成功。
