## 已有记录的词面观察 API

shared 与 Android VocabularyRepository 均提供：

```kotlin
suspend fun rememberSurfaceForms(
    entries: List<ContextualDictionaryEntry>
): VocabularySurfaceFormsUpdate
// result.savedWords: 当前持久化快照
// result.changed: 本次实际新增合法表面形并成功写入
```

可传 listOfNotNull(result.wordEntry, result.entry, result.relatedPhrase)，候选按现有 canonical ID 一次事务分组。只改变已存在记录的 surfaceForms/updatedAt，保留 meaning、AI 解释、原语境/图书、addedAt、reviewLevel/reviewCount/nextReviewAt。不存在或已删除 ID 不会新建；重复、大小写/空白等价、原型本身或非法短语单词碎片不会写盘，也不改 updatedAt。维持 8 个形态上限。只有真正新增合法形态时才清理该记录的旧错误碎片；普通载荷读不会改写旧数据。

IO 失败会抛出，字典 lookup 应独立保留原查询结果并处理观察失败；Cancellation 仍须传播，不发保存成功提示。changed=false 也返回当前持久化快照，可用于修正之前取消/并发后内存尚未更新的情形。AppViewModel lookup 接线归 root，本代理没有修改它。
