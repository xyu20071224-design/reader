# BUG-037 生词本（次级视图）顶栏仍显示外观 / 检查更新图标

- 严重程度：🟡 轻微
- 状态：待修复
- 置信度：高（代码直读可判定）
- 发现日期：2026-09-01
- 来源：GitHub issue #1 正文第 8 条
- 涉及文件：`src/app/src/main/java/com/linguareader/app/BookshelfScreen.kt`（196–253 行）

## 现象

「生词本作为次级菜单不应该有其他功能的图标，实际有」。

## 根因

顶栏 `actions` 里只有一部分动作做了视图判断：

```kotlin
// 197 行：书架外观 —— 无条件渲染
IconButton(onClick = { showAppearanceSheet = true }) { Icon(Icons.Default.Palette, ...) }
// 206 行：检查更新 —— 无条件渲染
IconButton(onClick = { showUpdateSheet = true }) { ... }
// 224 行：书架/生词本切换 —— 应当保留
// 235 行：只有 AI 中心与导入被收起
if (!showVocabulary) { ... }
```

切到生词本后，「书架外观」和「检查更新」这两个**属于书架的动作**依然在顶栏，
其中「书架外观」在生词本页面甚至改不了任何可见的东西。

## 修复建议

把 197–222 行两个 `IconButton` 一并纳入 `if (!showVocabulary)` 分支
（或反过来，抽一个 `ShelfActions` / `VocabularyActions` 两组动作，按视图切换），
生词本视图只留「返回书架」这一个动作。

顺带确认标题（176–194 行）在生词本视图下显示的是词数，这个是符合
「名字留次级页面」规约的，**不要一起删掉**。

## 回归验证

- `ShelfAppearanceTest.kt` / Compose UI 测试可断言：`showVocabulary = true` 时
  顶栏动作数量为 1。
- 真机截图两张（书架 / 生词本）进 `验证截图/`。
