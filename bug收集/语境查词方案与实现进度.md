# 语境查词：中文译本对照方案与实现进度

> 文档目的：便于分享与审阅，说明“英文原版 + 中文译本”下实现“点词返回本书语境译法”的方案设计、技术路线与当前实现/验证进度。

---

## 1. 背景

LinguaReader / 语境阅读 当前的“语境查词”已经具备完整本地闭环：

- WebView 点击取词：`word / sentence / paragraph / sentenceOffset`
- 本地离线词典（ECDICT，256 项 LRU 缓存）
- 词形还原、短语识别、语义核心词判定、词性推断与义项语境排序
- 查词面板：音标、释义、原形/短语提示、本句推断，支持收藏、朗读、复习
- 可选增强：DeepSeek 本书语境释义、术语表、Azure/DeepSeek 整句翻译

新的需求是：

> 用户已有一本英文原版书的中文译本。读英文版时，点击某个英文单词，期望返回“**中文译文里这个词在本句/本书中的真正译法**”，而不仅是词典义项。

---

## 2. 方案结论

**可行。** 本质是“双语文本对齐 / 翻译记忆（translation memory）”：

- 句子/段落级对齐：**可行性高**，适合作为第一期。
- 单词/短语级精确对齐：可行，但中文无空格、且有省略/意译/换序，需词典辅助 + 对齐模型 + AI 兜底，适合作为第二期。

关键约束：

- 需同一译本、章节结构与原版尽量一致，否则对齐质量下降。
- 译文并不总能逐词对应（如 `How do you do?` → “你好”里没有 `do`）。
- 对齐必须带**置信度**，宁可不标也不可错标。
- 隐私：用户的两本书与对齐档案都应留在本机。

---

## 3. 分期规划

### 第一期（整句对照）
- 用户为某本英文书关联一本中文译本。
- 本地完成：**章节 → 段落 → 句子**三级对齐。
- 点英文词时，返回中文译本中对应的**句子/段落**，并显示置信度。
- 无法精确对齐时降级为对应段落，不阻塞本地词典查词。

### 第二期（词级对照）
- 中文句内“对应词/短语”高亮。
- 组合：词典辅助匹配 + 本书术语表学习 + 本地词对齐模型 + AI 兜底。
- 支持用户手动校正并写回对齐档案，越用越准。

---

## 4. 技术设计（第一期）

### 4.1 数据模型
- `TranslationMemory`：按原书 ID 保存整本对齐结果（含 `terms` 本书术语表，可空）。
- `AlignedSentencePair`：英文句、中文句、英文段落、中文段落、章节号、置信度。
- `BookTerm`：`enWord → zhTerm`（count + confidence），由术语学习器在 attach 时生成。
- 存储位置（应用私有目录）：`files/translation-memory/<bookId>.json`。
- 中文译本导入到隐藏目录：`files/translations/<id>/`（不显示在书架）。

### 4.2 对齐流程
1. **章节对齐**：章节数一致时按序配对；不一致时用整章文本的动态规划对齐（允许跳过/合并）。
2. **段落对齐**：章节内按叶级段落（与阅读器/TTS 同一选择器）做单调序列 DP，允许 `1:0 / 0:1 / 1:1 / 2:1 / 1:2`。
3. **句子对齐**：在每个对齐段落内，用 `SentenceSplitter` 分句后再做小规模 DP 对齐。
4. 对齐代价 = 长度比偏差（英文词数 vs 中文有效字符数）+ 数字/拉丁专名锚点命中。
5. **术语表学习**：对齐完成后，`TermLexiconLearner` 从句对无监督学习 `enWord → 本书中译法`（字符 n-gram 跨句投票 + ECDICT 种子直配），随档案持久化。

### 4.3 查询流程
点词时按 `chapterIndex + 英文句/段落` 在 `TranslationMemory` 中查找：

- 优先：精确段落 + 精确句子（**先统一 `normalize`**：空白折叠、弯/直标点统一、标点转空格、小写）
- 其次：段落候选内的句子包含/重叠
- 再其次：句子级模糊（同章内 Dice 相似度 ≥ 0.85）→ 让更多点词进入词级高亮
- 兜底：对应段落
- 词级高亮：句级命中时 `WordAligner` 用【本书术语表偏好 + ECDICT 义项】定位中文词
- 输出：`TranslationLookupResult(中文句/段落, 英文句, 置信度, wordAlignment?)`

### 4.4 集成点
- `Book` 增加可选字段：`translationBookId / translationTitle / translationAlignedAt`。
- `LibraryRepository / LibraryFacade`：保存/移除译本关联。
- `TranslationMemoryRepository`：导入中文译本、生成/存储/查询对齐档案、学习术语表、删书时清理。
- 书架：每本书增加“加译本 / 译本”入口与状态（未关联/对齐中/就绪/失败）。
- 查词面板：新增“译本对照（《中文译本》）”区域，显示英文原句、中文对应句与置信度。
