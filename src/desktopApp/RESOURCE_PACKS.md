# 桌面资源包

桌面导航新增「资源包」。进入页面、切换服务器/GitHub、重新启动均不请求网络；只有「获取目录」和「下载并安装 / 重试」发起请求。本地导入和已安装列表可离线使用。服务器地址由 `RemotePackCatalog.DEFAULT_URL` 提供，可在页面手动修改；该设置独立于更新、历史版本和同步服务器。

服务器目录复用 shared 的 `RemotePackClient`，包括 HTTPS、大小与摘要验证、有摘要的断点重试及取消传播。GitHub 备用固定使用项目最新稳定 Release，由 `GitHubReleaseSource` 发现原始 `ReleaseAsset`，再交 `HttpReleaseTransport` 下载；未知/零大小资产不提供下载。控制器只接受当前来源本次发现的完整条目，换来源、改目录地址或刷新失败都会使旧选择失效。取消不会自动改用其他来源。

安装器复用 shared 的 `PackManifest`、`PackValidator`、`SafeZip`、`PackPaths`、`PackRegistry`；桌面只实现文件/JDBC适配。先拷贝、解压与校验至暂存区，再以原子登记表替换发布；提交前失败或取消会恢复原包。集合包成员逐个验证安装，失败会明确报告，已成功提交的成员保留。损坏登记表会显示错误并拒绝覆盖。包内词典还必须通过真实 SQLite 表结构探针。

词典包安装、切换、卸载后，现有桌面 Reader 的查词驱动会重新解析活动包。每次查询关闭 JDBC 连接，不保留阻止 Windows 卸载的打开句柄；缺失或打不开的活动词典回退已有默认词典。默认来源仍是 `-Dlr.dict`、数据目录 `dictionary/ecdict.sqlite` 或开发环境 assets。默认词典本来不存在时，卸载最后一个词典包后查词无命中，不会凭空生成词库。

当前桌面只消费词典包。音频/音色包可以导入、验证和卸载，但桌面听书仍使用原有引擎设置；页面明确说明该边界。音频包安装仍检查现行朗读管线版本，未更改任何已发布包格式。

原始日志与 XML 保存在执行副本 `artifacts/desktop-packs/`，不提交测试生成的词典包、SQLite、书籍、音频或日志。官方桌面构建依赖已按现有仓库配置下载；未下载 JCEF 浏览器内核。

## GUI 验收边界

编译和上述测试不证明窗口、文件选择器、排版或鼠标操作正常。交付时真实 GUI 验收仍待主代理执行。

验收应指定独立的 `-Dlr.home`、`-Duser.home` 和已创建的 `-Djava.io.tmpdir`。正常主窗口不会自行退出。资源包页面与书架、词库、设置本身不调用 JCEF；在没有浏览器内核的环境中，不要打开电子书触发原有 JCEF 初始化。

两个小型测试词典包与默认词典应在隔离目录中生成：查 `apples` 应归一到 `apple`，初始显示默认释义，安装第一包后显示第一包释义，切换第二包后显示第二包释义；重启保持第二包及离线列表；卸载活动第二包后回退默认释义且第一包仍保留。该消费链已由真实 SQLite/shared lookup 测试通过；GUI应另外检查导航、导入文件选择、状态反馈、当前词典标识和卸载确认。

桌面资源兼容版本常量当前为26，与本次 Android `versionCode` 一致。后续发布升版时需同步更新 `DesktopPackRepository.APP_VERSION`，不能把桌面安装包的 `1.0.0` 字符串当作资源兼容版本。
