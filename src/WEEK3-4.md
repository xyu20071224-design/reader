# 第三、四周交付说明

## 第三周：离线词典

- 将 ECDICT 的 770,611 个有效词条打包为只读 SQLite 资产。
- 从 ECDICT `exchange` 字段生成 66,630 条 `form → lemma` 关系。
- 支持规则和不规则词形还原，并保留启发式后备方案。
- 展示音标、词头、中文分义项和英文定义。
- 使用 256 项 LRU 风格内存缓存；查词全程离线。

## 第四周：语境与短语

- WebView 使用 `Intl.Segmenter` 提取当前英文句子，并提供兼容回退。
- 传递点击词在句中的精确偏移，解决同词多次出现时的定位问题。
- 生成包含点击词的 2–5 词窗口，对窗口内词形统一还原后查询短语。
- 完整短语优先于单词，例如：
  - `looked forward to` → `look forward to`
  - `took off` → `take off`
- 根据限定词、助动词、`to`、词尾等线索推断名词/动词/形容词/副词。
- 与推断词性一致的中文义项显示“本句优先”并排在前面。
- 处理 `U.S.` 等缩写、`well-known` 等连字符词和 `writer's` 等所有格。

## 验证结论

Debug 编译、JVM 单元测试、Android Lint 和 Android 15 / API 35 仪器测试均通过。手动模拟器验证了 EPUB 导入、分页阅读、`carried` 词形还原/动词义项置顶，以及在点击 `to` 时匹配 `look forward to`。
