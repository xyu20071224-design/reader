# Q1-t04 相邻句查询修复与档案回归

本批基于 Q1-t01 的 `b67a6bc`，只修改生产查询器及直接相关测试。未修改实验 `shared.alignment`、对齐阈值、档案格式、对齐器版本和共享 UI。

## 实际复现

新增 `AdjacentSentenceQueryRegressionTest`。相同 7 个测试在修复前出现 3 个失败，原始 XML 存于本副本 `artifacts/q1-t04/red-xml/`，日志为 `artifacts/logs/q1-t04-query-red-complete.log`。

| 触发情形 | 原行为 | 修复后允许行为 |
| --- | --- | --- |
| v6 档案合并存储 `The bird left. The bird left again.`，句译只有前句；查询后句 | contains 护栏拒绝后，Dice 去重 token 集又以句级返回前句译文 | 返回本段完整译文，标为 PARAGRAPH |
| 当前档案原段中有完整 B=`The old bird came.`，只存在较长 A=`The old bird came back.` 的句对 | 去标点后的 contains 把 B 视为 A 的片段 | 返回本段完整译文，标为 PARAGRAPH |
| 同上，但别段还存在同文 B 的句对 | 借用别段 B 的译法，覆盖已知本段上下文 | 返回当前段完整译文，标为 PARAGRAPH |

这三个触发点均通过真实 `TranslationMemoryIndex.lookup` 复现。修复只承认已知原段中、由生产断句器识别的完整源句；确为单句内部片段和正文已漂移的查询继续使用原有 contains、精确句或模糊回退。已知完整句缺少可信句对时诚实降级到段级，不生成或补造句译。

## 最小改动

1. 精确同段同句命中仍优先。未命中的完整源句若在本段缺少句对，直接走既有段级兜底及原置信度下限。
2. 旧档案的跨句片段护栏同时作用于 contains 和 fuzzy，不能被 Dice 集合丢失句序、次数的信息绕过。
3. v7 及之后的整段单句档案继续信任其单句契约，不对缩写、引语终止符再次套 v6 启发式。既有 Frodo 多终止符片段回归保留。

查询器行为不改变已落盘对齐结果，因此本批不再递增 VERSION；Q1-t01 的 VERSION=12 保持不变。
