# 变形单词完整划线验收

任务：Q1-t02。你负责完成本子项的复现、必要修复和验收。开始前读取 [总计划的共同执行约定](00-总计划.md#共同执行约定)，以其中指定的 GitHub 主分支基线建立隔离工作区。已有实现先验收；只有出现有证据的缺陷时才改产品代码。 来源：[issue 1 标题补充 2](https://github.com/xyu20071224-design/reader/issues/1)。

## 目标与当前依据

收藏原型后，正文里的规整变形应标记完整词面，不能只划原型的几个字母。生产 `ReaderCoreJs.savedWordVariants` 已覆盖 CVC 双写、y 变 i、词尾 e 变化，`span.textContent = match[0]` 保留正文拼写。

## 执行步骤

1. 在 Q1-b01 的标记实现上建立 run/running、stop/stopped、study/studies/studied、make/making 的正例和仅含相同字母的负例。
2. 记录保存时 headword、surfaceForms 和最终标记的 DOM 文本；断言标记完整 running，而非 run 子串，且不得改写词面或大小写。
3. 用原型和已保存表面形分别触发查词收藏，验证变形表去重、同章重复、换章、重启和取消收藏。
4. 在普通生词和到期生词两种状态下执行同样样本，确保两种样式共用形态规则。
5. 未通过时只修已复现的形态处理；不把规则变成无约束的词干子串匹配。不规则形态按 Q1-t08 的已见表面形契约验收。

## 改动边界

与 Q1-b01 共用 `ReaderCoreJs.kt`、`SavedWordMarks.kt`、`ReaderController.kt`。等 Q1-b01 完成后串行修改；允许新增独立 `SavedWordInflectionInstrumentedTest`。不改词典的全局词性/词形推断以凑过标记用例。

## 验收条件

所有事前锁定的正例 span 与正文完整词面逐字一致，负例零误标；普通/到期样式都没有半词划线。重复注入、换章、重启不产生残壳、词面覆盖或阅读位置跳动。

## 验证与交付

交付每个原型到表面形的固定用例表、真实 WebView DOM 断言及相关 JVM/JS 回归结果。报告中区分当前规则承诺与新发现的词法扩展，不能把未见过的不规则词假装自动识别通过。
