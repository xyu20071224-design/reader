# 验收清单 · v1.10.0（versionCode 19）

> **面向**：PKP110 / Android 16（历史验证设备）或任意 minSdk 23+ 设备。
> **方法**：装 Release 资产 `LinguaReader-v1.10.0.apk`，**覆盖安装、不要卸载**（卸载会清掉书库与生词）。
> **填写**：每项写「✅ 通过 / ❌ 不通过 / ⚠️ 部分」，不通过请附**一句话现象 + 截图**（截图放 `验证截图/`）。
> **本版改动面**：译本对照对齐器 v7、档案版本闸门 + 「重新对齐」入口、词级高亮与释义互指、TTS 管线版本 2→3。

## A. 安装与版本（先做，不通过就停）

- [ ] **A1** 覆盖安装成功，**没有**要求先卸载、**没有**签名冲突报错。
- [ ] **A2** 装完后应用内/系统应用信息显示 **1.10.0**（versionCode 19）；书库、生词、设置**都还在**。
- [ ] **A3** 打开一本原来能读的书，阅读位置与上次一致（覆盖安装不清数据）。

## B. 本次核心：`Q1-t04`「A 句后的 B 句返回 A 句意思」

> 只对**有中文译本对照**的书做（出版译本或 AI 译本都行）。看查词面板里的「译本对照」区块。

- [ ] **B1** 点一个**长段落中间偏后**的英文句：译文**要么**是这句对应的中文，**要么**明确标注「**段级（未定位到句）**」并显示整段译文。
      **不通过判据**：标成句级、但内容其实是**前一句**的意思。
- [ ] **B2** 专找「两句英文 ↔ 一句中文」的段落（英文两个句号、中文一个句号）：
      - 点**第一句** → 应得到那句中文，标句级；
      - 点**第二句** → 应显示「段级（未定位到句）」+ 整段译文。
      这是**有意**的降级（第二句不再有句级条目），**不是** bug。
- [ ] **B3** 抽查 **10 句**，记下三类各几例：句级 ? / 段级 ? / 内容明显不对 ?（数字给我即可，用来判断方向对不对）

## C. 新功能：档案版本闸门 +「重新对齐」（本版最需要验的一项）

- [ ] **C1** 书架 → 某本有对照的书 → 打开该书菜单：旧档案的书应出现「**对照待更新**」提示与「**重新对齐**」入口（本版之前的书都是旧档案，所以应该看得到）。
- [ ] **C2** 点「重新对齐」：应立刻出现**进行中**状态（书卡「对齐中…」/ 按钮禁用 / 不能重复点），完成后有全局 Snackbar 提示成功（含句对数与耗时）。
- [ ] **C3** 重对齐完成后再点同一批句子：对照结果应当**变好或至少不更差**（这是 v7 对齐器生效的证据）。
- [ ] **C4** 找一本**没有译本**的书：不应出现「重新对齐」入口；**既有对照档案不得被清空**。
- [ ] **C5 耗时与卡顿**（我一直没法在设备上量的项）：记录整本重对齐**大约多少秒**、期间界面是否可滑动、是否卡顿/被系统杀掉。

## D. `Q1-t09`：词级高亮与释义互相指认

- [ ] **D1** 点一个英文词：查词面板里应有**一行义项被高亮标出**（强调色 + 加粗）；若那一行不是「本句优选」，旁边显示「**高亮来源**」。
- [ ] **D2** 判据：被高亮的那行中文词，应当**能在对照译文里找到**，且与标出的义项一致。
      **不通过判据**：高亮的词和你正在看的那条释义对不上（这正是本版修的问题）。
- [ ] **D3** 抽查 5 个多义词（如 `bank` / `spring` / `light` / `charge` / `sentence`），记录是否仍错配。

## E. 回归面（本版波及到的路径）

- [ ] **E1** 点词查词：响应**没有变慢**、释义正常（本版给查词路径多传了真实句子上下文与词典包来源）。
- [ ] **E2** 导入一本书（EPUB / TXT）→ 打开 → 翻页 → 改字号，均正常。
- [ ] **E3** 听书：点一句能读。注意**本版把朗读管线版本 2→3，旧音频缓存作废**——首次播放某句会重新合成（比平时慢一点属预期），之后恢复。
- [ ] **E4** 复习：进复习卡片能翻卡、能评分，退出重进进度不丢。
- [ ] **E5** 云同步（若在用）：设置里能开关、能登录/立即同步，不报错。
- [ ] **E6** 书架「检查更新」：能看到 1.10.0（本版就是最新）。

## F. 本版**没有**做的（别当成 bug）

- 低置信 / 长度比不合格的句对**仍然不落盘**（「宁可不产，不可错配」是既定设计）→ 这些句子只有段级对照。
- **不自动**重对齐：必须手动点「重新对齐」。
- 整本 AI 翻译失败（`Q1-b02`）**仍挂起**，未修（状态记录见 `议题整理/待办-整本AI翻译失败.md`）。
- 听书断句：`students’ books`（词尾所有格撇号）、`’tis`/`’em`（词首省略撇号）**仍会被当作引号**——本轮只豁免了词内撇号。
