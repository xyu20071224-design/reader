## 一、连接自检：手机真实可见，通道 = USB（须放开 /dev/bus/usb）

### 1.1 探测命令与原始输出

```bash
$ lsusb

$ cat /sys/bus/usb/devices/3-10.3/{manufacturer,product,serial,idVendor,idProduct,authorized}

product      = PKB110
serial       = ZXJRNJVWY9C6BYDA
idVendor    = 22d9
idProduct   = 2769
authorized  = 1

$ # 接口类：ff/42/01 = ADB 接口（无内核驱动 = Android 正常形态）
$ cat /sys/bus/usb/devices/3-10.3:1.0/{bInterfaceClass,bInterfaceSubClass,bInterfaceProtocol}
ff 42 01

$ adb devices -l
List of devices attached
ZXJRNJVWY9C6BYDA       device usb:3-10.3 product:PKB110 model:PKB110 device:OP5A3DL1 transport_id:1
```

### 1.2 通道矩阵

| 通道 | 命令 | 结果 | 可用 |
| --- | --- | --- | --- |
| USB / adb | `adb devices -l` | 见上，device 在线 | ✅ |
| USB / fastboot | `fastboot devices` | 空 | —（设备在 adb 模式，非 bootloader） |
| TCP 5555 | `adb connect 127.0.0.1:5555` | `Connection refused` | ❌ |
| 无线调试 mDNS | `adb mdns services` | 列表为空 | ❌ |
| USB 网络（RNDIS/NCM） | `ip -br addr` | 只有 `lo`/`enp131s0`/`wlan0(DOWN)` | ❌ |

**结论：唯一通道是 USB。** 无替代路径。

### 1.3 根因（已用一次提权重试证实）

- `workspace-write` 模式下 `/dev` 是 **只读 devtmpfs**，**不存在 `/dev/bus/usb`** → adb 拿不到设备节点 → `adb devices` 为空。
- 放开到 `danger-full-access` 后，`/dev/bus/usb/003/` 出现，**同一台手机立刻列出**。
- 即：**不是授权问题、不是驱动问题、不是线材问题**，无需你在手机上点任何东西。
