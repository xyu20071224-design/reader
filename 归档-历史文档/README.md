## 移动方式

- **已入库文件**（`工作总结-BUG-021…`、`发版瘦身-R8…`、`译本对齐-质量画像-魔戒.md`）用 `git mv`，
  历史与重命名记录完整。
- **从未入库文件**（其余 9 个）用普通 `mv`：`git mv` 对它们直接报
  "致命错误：不在版本控制之下"，而这些文件本来就**没有任何 git 历史可保留**，移动不影响完整性。
