## 3. 改动一：JS 注入转义缺陷（已进 `5c36f2c`）

### 根因

`ReaderScripts.bootstrap()` 把两条**本地化提示文案**裸拼进单引号 JS 字面量：

```kotlin
hint.textContent = '$scrollEndHint';     // 旧写法
hint.textContent = '$scrollStartHint';
```

而同文件其余注入值（主题色/字号/行距/生词表）全部规规矩矩走 `JSONObject.quote`。

### 影响

只要某条翻译带撇号（英文里 `chapter's end` 这类极常见），整段 bootstrap IIFE 就是**语法错误** → 脚本注入失败 → **正文白屏、翻页全失效**。当前中英文案恰好不含撇号，属于潜伏缺陷（latent），不是当前故障。

### 修复

`bootstrap()` 由表达式体改为块体，先转义再拼：

```kotlin
val endHintLiteral = JSONObject.quote(scrollEndHint)
val startHintLiteral = JSONObject.quote(scrollStartHint)
// …
hint.textContent = $endHintLiteral;
```

`JSONObject.quote` 同时处理 `"`、`\`、换行/控制字符，并把 `</` 转成 `<\/`，与全文件其余注入点统一约定。生成脚本除这两行外逐字节不变。

### 回归测试

新增 `ReaderScriptsTest.scrollHintsAreInjectedAsEscapedJsLiterals`：用同时含 `'`、`"`、`\` 的文案断言输出为 `hint.textContent = "chapter's end \" \\ next";`，并用 `assertFalse` 钉死旧的裸单引号写法不能回来。

## 4. 改动二：CI 门禁 / 预览 / 测试锚点（已进 `07b437c`）

### 4.1 CI 加 Android Lint

- `.github/workflows/ci.yml`：新增 `lint` job（与单测并行），跑 `:app:lintDebug`，报告上传为 `lint-report-debug` artifact。
- `src/app/build.gradle.kts` 新增 `lint {}`：`checkReleaseBuilds = false`（源码一份，只跑 debug）、`abortOnError = true`、`warningsAsErrors = false`（未做过整轮清理，全量升级会红几百条没人看）、三种报告落盘。

**⚠️ 这一项是本轮唯一没能本地验证的东西**：开发机离线（`build.ps1` 里配的代理 `127.0.0.1:7890` 连接被拒），`com.android.tools.lint:lint-gradle:31.9.1` 不在本地 Gradle 缓存里，`lintAnalyzeDebug` 直接卡在依赖解析。因此**没有**把一个未经验证的门禁直接设成阻断，首轮用 `continue-on-error: true` 观察，并在 workflow 注释里写明收紧条件。

### 4.2 `@Preview`（0 → 7 个）

新增 `UiPreviews.kt`，核心是 **`PreviewScaffold`**：复刻 `MainActivity` 的「`LocalLinguaPalette` + `colorSchemeFor` + 纸色 `Surface`」。少了这层，组件在预览里拿的是 Material 默认配色与兜底调色板，夜间组件会全程显示成浅色 —— 预览会说谎。

已有预览：听书条（日间 / 夜间 / **全书缓存进行态**，320dp 窄屏最易挤坏）、复习提醒横幅（日间 / 夜间，`dwellMillis = 0` 关掉自动消失的 `LaunchedEffect`）、空书架（日间 / 夜间，写在 `BookshelfScreen.kt` 内因为 `EmptyBookshelf` 是 private）。

**故意不做**：`ModalBottomSheet` 类弹层走独立 window，预览基本空白，加了是负债。

### 4.3 关键 `testTag`（3 → 15 处）

新增 `UiTags.kt`：14 个常量 + `bookCard(bookId)` 动态标签（同名书不撞），按区域分组。

| 区域 | 挂载点 |
| --- | --- |
| 书架 | 导入 / 生词本 / AI 中心 三个图标动作、书卡网格、空书架、每张书卡 |
| 阅读器 | 正文 WebView、顶栏、听书条、目录弹层、设置弹层、查词弹层、跳页对话框 |
| 复习 | 复习卡弹层、到期提醒横幅 |

顶栏三个动作在上一版刚"图标化"（删掉可见文字），正是最需要稳定 id 的地方。

- **工作区 = `C:\work\reader`（全英文）**；镜像 `C:\Users\Public\work\语境阅读` 内容相同但不是主仓。
- **工具链在 `C:\work\toolchain`，不在 `C:\work\reader\toolchain`**（根目录 `工作总结.md` §7 那句路径有误）。构建/测试一律用 `& 'C:\work\toolchain\build.ps1' <gradle 参数>`：JAVA_HOME / ANDROID_HOME / GRADLE_USER_HOME 都在里面，**系统 PATH 上没有 java**。
- **这台机器离线**：代理 `127.0.0.1:7890` 拒绝连接。凡是本地 Gradle 缓存没有的依赖一律拿不到 —— 已知拿不到的：`lint-gradle`（→ lint 跑不了）、`ui-test-junit4`/`espresso`/`test.ext:junit`（→ androidTest 编译不了）。跑 `lintDebug` 前先确认有网。
- **UI 测试新写法**：定位节点优先用 `UiTags` 常量，不要按文案（双语各 557 条，按文案定位天然易碎）。
- **改 `ReaderScripts` 的铁律**：任何拼进 JS 的外部字符串（尤其来自 `strings.xml` 的文案）必须走 `JSONObject.quote`，不要裸拼进引号里。
